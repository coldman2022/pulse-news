# Pulse — вебсайт із RSS-новинами

## Публікація на GitHub Pages

Додано статичну збірку та workflow `.github/workflows/pages.yml`. Наявність цих файлів сама по собі не означає, що сайт уже опублікований.

1. Об’єднайте pull request із цими змінами в `main`.
2. Відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Відкрийте **Actions → Update news and deploy Pages → Run workflow**, виберіть `main` і запустіть.
4. Дочекайтеся успіху завдань `test`, `build` і `deploy`. Справжня адреса сайту буде у результаті `deploy` та в **Settings → Pages → Visit site**. Очікувана адреса: https://coldman2022.github.io/pulse-news/ . Відкрийте її й перевірте наявність новин та час збору RSS.

**Репозиторій зараз приватний.** GitHub Pages у приватному репозиторії потребує відповідного платного тарифу GitHub. На GitHub Free потрібен публічний репозиторій. Зміна видимості відкриває код та історію, тому це окреме рішення власника. Не змінюйте видимість лише для усунення помилки збірки без перевірки вмісту.

Документація: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Як працює вебверсія

- GitHub Actions збирає BBC World, The Guardian і Hacker News при змінах у `main`, ручному запуску та щогодини на 17-й хвилині. Розклад може запускатися із затримкою.
- Python створює `_site/news.json` і копіює інтерфейс у `_site/`. GitHub Pages публікує лише цю папку. Постійно працюючий Python-сервер для вебверсії не потрібен.
- Браузер перевіряє опублікований файл кожні 5 хвилин. Кнопка «Оновити стрічку» перечитує його; вона не запускає новий збір RSS. Час «Збір RSS» показує час підготовки опублікованих даних.
- Знімок попередніх новин зберігається в кеші Actions. Якщо одне джерело недоступне, за наявності кешу використовуються його попередні матеріали з позначкою. Кеш може бути видалений GitHub; це не постійна база даних.
- Якщо всі джерела недоступні або стрічка порожня, збірка завершується помилкою, а раніше опублікований сайт залишається. За першого запуску в такому разі сайт не публікується.
- Pull request запускає тести й повну збірку з перекладом; результат доступний як артефакт `pulse-preview`. Публікації з гілки PR немає. Workflow не змінює файли репозиторію й не потребує особистих токенів або API-ключів.
- Збереження новин працює в поточному браузері й не синхронізується між пристроями. Заголовки та описи у вебверсії автоматично перекладає Argos; повна стаття відкривається мовою видання або через Google Translate.

## Автоматичний переклад українською

- Під час збірки `python build_site.py --translate` Argos Translate перекладає англійські заголовки та короткі RSS-описи. Повні статті з сайтів видань не завантажуються для перекладу.
- Використовуються Argos Translate 1.11.0 і офіційна модель en → uk 1.4. Модель має обмежену якість: може помилятися в іменах, термінах, числах і навіть спотворювати зміст. Перекладені матеріали позначені «Автопереклад», оригінал можна розгорнути під новиною. Це допоміжний переклад, а не перевірений редактором текст.
- API-ключі, сторонній обліковий запис і платіжна картка не потрібні. Після завантаження моделі тексти перекладаються на сервері GitHub Actions, без зовнішнього сервісу перекладу. Для поділу англійського тексту на речення використовуються локальні правила spaCy, без додаткових моделей із мережі.
- Файл моделі завантажується лише за відсутності кешу; перевіряється SHA-256. Модель і залежності не публікуються на Pages.
- Готові переклади зберігаються в кеші Actions за хешем тексту та версією моделі. Незмінний текст повторно не перекладається; зміни опису викликають новий переклад. Кеш обмежений 5000 фрагментами й може бути видалений GitHub.
- На переклад нових фрагментів виділено до 6 хвилин між запитами до моделі. Якщо час вичерпано, модель недоступна або фрагмент не перекладено, показується оригінал. Наступна збірка повторить спробу. Перший запуск із завантаженням залежностей довший за наступні.
- Пошук працює і за оригіналом, і за перекладом. Уже збережені раніше англійські матеріали залишаються у браузері в попередньому вигляді.
- Ця модель призначена для англомовних джерел, які зараз указані в `sources.json`. Для інших мов потрібні окремі моделі та визначення мови.

Для локальної збірки з перекладом використовуйте окреме Python-середовище:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-translate.txt
python translate_news.py --install --smoke-test
python build_site.py --translate
python -m http.server 8000 --directory _site
```

Без `--translate` зберігається попередній режим без Argos. Локальний `server.py` теж продовжує показувати оригінальні RSS-тексти. У GitHub Actions переклад увімкнено автоматично після об’єднання PR; нових налаштувань Pages не потрібно.

## Перевірка та локальний запуск

Потрібен Python 3.10+. Додаткові Python-бібліотеки не потрібні.

```sh
python3 -m unittest -v
python3 build_site.py
python3 -m http.server 8000 --directory _site
```

Відкрийте http://localhost:8000/ . Альтернатива зі збором RSS при запиті: `python3 server.py`, адреса http://127.0.0.1:8765/ . Обидва режими використовують один RSS-парсер.

Тести перевіряють RSS/Atom, небезпечні посилання, часткову недоступність джерел, створення статичного сайту та збереження останнього знімка при повній відмові. Живі RSS перевіряються окремо командою `python3 build_site.py`; тести не залежать від мережі.

## Що сталося з попередніми файлами

У поточній сесії немає `/mnt/data` і попередніх ZIP, інструкції та PNG. Доступний запис попереднього чату не містить вихідного коду або повного опису реалізації. Тому це нова збірка за доступним контекстом, а не відновлена копія. Точну відповідність старому дизайну та функціям підтвердити неможливо.

## Завантажте й запустіть

1. Збережіть `pulse-news-mvp.zip` на комп’ютер і розпакуйте. Не запускайте файли всередині нерозпакованого ZIP.
2. Потрібен **Python 3.10 або новіший**. Якщо його немає, встановіть із https://www.python.org/downloads/ . У Windows увімкніть додавання Python до PATH.
3. Відкрийте термінал у розпакованій папці `pulse-news-mvp`, де лежить `server.py`.
   - macOS: у Terminal введіть `cd ` (із пробілом), перетягніть цю папку у вікно й натисніть Enter.
   - Windows: відкрийте папку в Провіднику, введіть `powershell` в адресному рядку й натисніть Enter.
4. Запустіть:

   macOS / Linux:
   ```sh
   python3 server.py
   ```

   Windows:
   ```powershell
   py -3 server.py
   ```
5. Відкрийте **http://127.0.0.1:8765** у браузері. Перше завантаження зазвичай потребує кількох секунд; недоступне джерело може збільшити час очікування.
6. Залишайте термінал відкритим, доки читаєте новини. Для зупинки натисніть Ctrl+C.

Нічого додатково встановлювати через pip/npm не потрібно. API-ключі та платні підписки не потрібні. Не відкривайте `static/index.html` подвійним клацанням — для новин потрібен сервер.

## Що є в цій збірці

- Живі RSS-новини BBC World, The Guardian і Hacker News.
- Теми «Світ» і «Технології» визначаються налаштуванням джерела, а не аналізом кожного матеріалу.
- Пошук за завантаженими заголовками й описами; фільтри джерел і тем.
- Сортування за датою, усунення точних повторів URL.
- Збереження новин у поточному браузері. Збережене доступне після перезавантаження; очищення даних браузера його видаляє. Між пристроями воно не синхронізується.
- Оновлення раз на 5 хвилин, поки сторінка відкрита. Кнопка «Оновити стрічку» повторює запит; сервер використовує кеш до 5 хвилин, щоб не перевантажувати джерела.
- Окремий статус недоступних джерел. Якщо джерело перестало відповідати під час роботи сервера, показуються останні успішно отримані новини з позначкою. Після зупинки сервера цей кеш очищається.
- Адаптивний інтерфейс українською.

## Безкоштовний переклад

«Перекласти українською» відкриває матеріал через Google Translate в окремій вкладці. URL статті передається Google. Підтримується переклад сайтів: https://translate.google.com/ . Деякі видання блокують перекладач або обмежують доступ. У такому разі відкрийте оригінал і скористайтеся перекладом браузера. Автоматичного перекладу заголовків усередині Pulse немає; платного API також немає.

## Змінити джерела

Відредагуйте `sources.json` у текстовому редакторі. Для кожного джерела вкажіть `name`, `url` із публічним RSS/Atom і `category` («Світ» або «Технології»). Дотримуйтеся формату JSON. Потім зупиніть та знову запустіть сервер. Нові категорії потребують додавання відповідної кнопки в `static/index.html`.

## Якщо щось не працює

- **Команду python3 / py не знайдено:** встановіть Python і знову відкрийте термінал.
- **Порт зайнятий:** запустіть `python3 server.py --port 8766` (Windows: `py -3 server.py --port 8766`), відкрийте http://127.0.0.1:8766 . Збережене прив’язане до адреси й порту браузера.
- **Порожня стрічка:** перевірте інтернет, статус джерел, пошук і фільтри. Новини не замінюються вигаданими прикладами.
- **Не завантажуються RSS через сертифікати:** використовуйте актуальний Python; у macOS офіційний інсталятор Python містить `Install Certificates.command`. Не вимикайте перевірку HTTPS.
- **Стаття не перекладається:** відкрийте оригінал; доступність зовнішнього перекладу залежить від видавця та Google.

## Межі MVP та зміни

Нова реалізація: Python зі стандартною бібліотекою + HTML/CSS/JavaScript, новий дизайн Pulse, три вказані джерела та зовнішній переклад. Це локальний інструмент для одного користувача: він доступний лише на цьому комп’ютері. Публічний хостинг, облікові записи, серверна база збереженого, фоновий збір при закритому застосунку, AI-підсумки, об’єднання різних статей про одну подію й автоматичний переклад не реалізовані. Склад попередньої версії невідомий, тому назвати ці можливості «видаленими» не можна.

## Перевірка

Під час підготовки перевірено живі відповіді всіх трьох джерел (92 матеріали), пошук, тему «Технології» (20 матеріалів), збереження після перезавантаження, синтаксис JavaScript і три тести RSS/Atom та часткової відмови джерела. Кількість новин надалі змінюватиметься. PNG — новий скриншот цієї збірки. Після пакування архів перевіряється на CRC, розпаковується і запускається окремо.

Для повторення тестів у папці проєкту: `python3 -m unittest -v` (Windows: `py -3 -m unittest -v`).
