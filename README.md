# Pulse — почніть тут

Відтворена локальна версія MVP, 27 жовтня 2026 року.

## Що сталося з попередніми файлами

У поточній сесії немає `/mnt/data` і попередніх ZIP, інструкції та PNG. Доступний запис попереднього чату не містить вихідного коду або повного опису реалізації. Тому це нова збірка за доступним контекстом, а не відновлена копія. Точну відповідність старому дизайну та функціям підтвердити неможливо.

## Завантажте й запустіть

1. Збережіть `pulse-news-mvp.zip` на комп’ютер і розпакуйте. Не запускайте файли всередині нерозпакованого ZIP.
2. Потрібен **Python 3.10 або новіший**. Якщо його немає, встановіть із https://www.python.org/downloads/ . У Windows увімкніть додавання Python до PATH.
3. Відкрийте термінал у розпакованій папці `pulse-news-mvp`, де лежить `server.py`.
   - macOS: у Terminal введіть `cd ` (із пробілом), перетягніть цю папку у вікно й натисніть Enter.
   - Windows: відкрийте папку в Провіднику, введіть `powershell` в адресному рядку й натисніть Enter.
4. Запустіть:

   macOS / Linux:
   ```sh
   python3 server.py
   ```

   Windows:
   ```powershell
   py -3 server.py
   ```
5. Відкрийте **http://127.0.0.1:8765** у браузері. Перше завантаження зазвичай потребує кількох секунд; недоступне джерело може збільшити час очікування.
6. Залишайте термінал відкритим, доки читаєте новини. Для зупинки натисніть Ctrl+C.

Нічого додатково встановлювати через pip/npm не потрібно. API-ключі та платні підписки не потрібні. Не відкривайте `static/index.html` подвійним клацанням — для новин потрібен сервер.

## Що є в цій збірці

- Живі RSS-новини BBC World, The Guardian і Hacker News.
- Теми «Світ» і «Технології» визначаються налаштуванням джерела, а не аналізом кожного матеріалу.
- Пошук за завантаженими заголовками й описами; фільтри джерел і тем.
- Сортування за датою, усунення точних повторів URL.
- Збереження новин у поточному браузері. Збережене доступне після перезавантаження; очищення даних браузера його видаляє. Між пристроями воно не синхронізується.
- Оновлення раз на 5 хвилин, поки сторінка відкрита. Кнопка «Оновити стрічку» повторює запит; сервер використовує кеш до 5 хвилин, щоб не перевантажувати джерела.
- Окремий статус недоступних джерел. Якщо джерело перестало відповідати під час роботи сервера, показуються останні успішно отримані новини з позначкою. Після зупинки сервера цей кеш очищається.
- Адаптивний інтерфейс українською.

## Безкоштовний переклад

«Перекласти українською» відкриває матеріал через Google Translate в окремій вкладці. URL статті передається Google. Підтримується переклад сайтів: https://translate.google.com/ . Деякі видання блокують перекладач або обмежують доступ. У такому разі відкрийте оригінал і скористайтеся перекладом браузера. Автоматичного перекладу заголовків усередині Pulse немає; платного API також немає.

## Змінити джерела

Відредагуйте `sources.json` у текстовому редакторі. Для кожного джерела вкажіть `name`, `url` із публічним RSS/Atom і `category` («Світ» або «Технології»). Дотримуйтеся формату JSON. Потім зупиніть та знову запустіть сервер. Нові категорії потребують додавання відповідної кнопки в `static/index.html`.

## Якщо щось не працює

- **Команду python3 / py не знайдено:** встановіть Python і знову відкрийте термінал.
- **Порт зайнятий:** запустіть `python3 server.py --port 8766` (Windows: `py -3 server.py --port 8766`), відкрийте http://127.0.0.1:8766 . Збережене прив’язане до адреси й порту браузера.
- **Порожня стрічка:** перевірте інтернет, статус джерел, пошук і фільтри. Новини не замінюються вигаданими прикладами.
- **Не завантажуються RSS через сертифікати:** використовуйте актуальний Python; у macOS офіційний інсталятор Python містить `Install Certificates.command`. Не вимикайте перевірку HTTPS.
- **Стаття не перекладається:** відкрийте оригінал; доступність зовнішнього перекладу залежить від видавця та Google.

## Межі MVP та зміни

Нова реалізація: Python зі стандартною бібліотекою + HTML/CSS/JavaScript, новий дизайн Pulse, три вказані джерела та зовнішній переклад. Це локальний інструмент для одного користувача: він доступний лише на цьому комп’ютері. Публічний хостинг, облікові записи, серверна база збереженого, фоновий збір при закритому застосунку, AI-підсумки, об’єднання різних статей про одну подію й автоматичний переклад не реалізовані. Склад попередньої версії невідомий, тому назвати ці можливості «видаленими» не можна.

## Перевірка

Під час підготовки перевірено живі відповіді всіх трьох джерел (92 матеріали), пошук, тему «Технології» (20 матеріалів), збереження після перезавантаження, синтаксис JavaScript і три тести RSS/Atom та часткової відмови джерела. Кількість новин надалі змінюватиметься. PNG — новий скриншот цієї збірки. Після пакування архів перевіряється на CRC, розпаковується і запускається окремо.

Для повторення тестів у папці проєкту: `python3 -m unittest -v` (Windows: `py -3 -m unittest -v`).
